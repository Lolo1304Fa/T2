BOULDER ESCAPE - STICKMAN NARANJA

Abre esta carpeta en Visual Studio Code.
Instala Live Server (Ritwick Dey) si aún no la tienes.
Clic derecho en index.html > Open with Live Server.
Se necesita internet para cargar la librería Three.js desde jsDelivr.

Controles:
A: izquierda.
D: derecha.
El avance se simula automáticamente.

El stickman naranja está construido con SphereGeometry y CylinderGeometry,
no requiere FBX ni modelos descargados.
El avance es automático, simulado moviendo camino y obstáculos.
La roca está detrás y gira constantemente. Sin colisiones ni Game Over,
según las consideraciones de la evaluación T2.

Archivos:
index.html - página web
juego.js - código Three.js
piedra.png - textura para la esfera de roca
